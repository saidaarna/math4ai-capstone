# `data/`

This folder contains the **fixed input datasets** for the capstone project. These files are shared identically across all teams and must not be modified, replaced, or supplemented with external data.

---

## Files

### `digits_data.npz`
- **Content:** Flattened 8×8 pixel digit images from scikit-learn's Digits dataset
- **Shape:** 1797 samples × 64 features, integer labels 0–9
- **Scaling:** Features are pre-scaled to the interval [0, 1] — **do not apply further normalization**
- **Keys:** `X` (features), `y` (labels)
- **Use:** Load with `np.load('digits_data.npz')`

### `digits_split_indices.npz`
- **Content:** Fixed train / validation / test index arrays shared across all teams
- **Keys:** `train_idx`, `val_idx`, `test_idx`
- **Purpose:** Ensures fair, identical comparison between Softmax Regression and the NN; prevents test-set leakage into model selection
- **Policy:** All digits experiments must use exactly these indices. Do not re-split the data.

### `linear_gaussian.npz`
- **Content:** Synthetically generated dataset of two 2D Gaussian blobs with mild overlap
- **Shape:** k=2 classes, d=2 features
- **Purpose:** Geometrically linear task — the Bayes-optimal decision boundary is a hyperplane, so a linear model is sufficient
- **Generated by:** `starter_pack/scripts/generate_synthetic.py`

### `moons.npz`
- **Content:** Synthetically generated interlocking crescent dataset
- **Shape:** k=2 classes, d=2 features
- **Purpose:** Geometrically nonlinear task — no affine hyperplane can separate the classes, motivating the hidden layer
- **Generated by:** `starter_pack/scripts/generate_synthetic.py`

## Loading Example

```python
import numpy as np

# Digits
data    = np.load('starter_pack/data/digits_data.npz')
X, y    = data['X'], data['y']

split   = np.load('starter_pack/data/digits_split_indices.npz')
X_train = X[split['train_idx']]
X_val   = X[split['val_idx']]
X_test  = X[split['test_idx']]

# Synthetic tasks
gauss = np.load('starter_pack/data/linear_gaussian.npz')
moons = np.load('starter_pack/data/moons.npz')
```
