# `figures/`

This folder contains all report-ready and slide-ready plots generated by the experiment scripts. Figures are created automatically when the scripts in `starter_pack/scripts/` are executed — do not edit them by hand.

## Regenerating Figures

All figures are regenerated by running the corresponding script from the repository root:

```powershell
# Data inspection figures (requires Jupyter)
jupyter nbconvert --to notebook --execute starter_pack/scripts/inspect_data.ipynb

python starter_pack/scripts/run_experiments.py   # core experiment figures
python starter_pack/scripts/run_ablations.py     # ablation and optimizer figures
python starter_pack/scripts/run_track_b.py       # Track B figures
```

## Usage in the LaTeX Report

In `starter_pack/report/main.tex`, figures are referenced using a relative path from the report root:

```latex
\includegraphics[width=\textwidth]{figures/gaussian_sr.png}
```

In `starter_pack/slides/presentation.tex`, data-inspection figures are referenced as:

```latex
\includegraphics[width=\textwidth]{data_inspect_figures/inspect_gaussian.png}
```

When uploading to Overleaf, place the entire `figures/` folder (including `data_inspect_figures/`) alongside `main.tex`.
